# Vortex Cosmetics

Cape catalogue for Vortex Client. Nothing else belongs in here.

## Setup

The repository **must be public**. A private one answers 404 to everyone
except your logged-in browser — which is exactly what went wrong before.

After creating it, replace `BENUTZER` and `REPO` in `cosmetics.json` with
your account and repository name. Both addresses, two lines.

## Adding a cape

1. 64x32 PNG into `cosmetics/`
2. Preview image into `cosmetics/preview/` (same file name)
3. Entry in `cosmetics.json`

`id` must never change after release — it is stored in every player's choice.
